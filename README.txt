KaraokeLocal v0.5.56

GitHub向けの詳しい説明・使い方・更新履歴は README.md を参照してください。

公開版:
  KaraokeLocal.exe をダブルクリック（Python不要）
  EXEのショートカットを作成して起動可能

開発版 / ソース版:
  start.bat

TOP画面:
  http://<PCのIP>:13585/

フォルダから選曲:
  http://<PCのIP>:13585/folder-browser

予約曲リスト:
  http://<PCのIP>:13585/queue

リモコン:
  http://<PCのIP>:13585/remote

表示画面:
  http://<PCのIP>:13585/display

管理画面:
  5963 → メモリーセット → 管理者パスワード → メモリーセット
  ※管理画面URLはPCごとにランダム生成され、固定の /admin は使用しません。

初期管理者パスワード:
  0000

本体の終了:
  管理者認証後の管理画面 → 「9. 危険操作」→「KaraokeLocalを終了」
  本体PC / スマホ / 別PCから実行可能

新規環境の参加者初期値:
  Aさん
  Bさん
  Cさん

PC固有データ:
  %LOCALAPPDATA%\KaraokeLocal\

KaraokeLocal本体のライセンス条件は現時点では未指定です。
第三者ライブラリについては THIRD_PARTY_NOTICES.md を参照してください。


楽曲DB構成:
  単一DBモード
  複数DBモード（DB 1つ ↔ 動画ルート 1つ、最大99組）

複数DBモードは管理画面の「3. 基本設定」から設定できます。


再生プレイヤー:
  VLC固定です。
  管理画面でVLC.exeを設定できます。

再生操作:
  一時停止
  再生
  はじめから
  演奏停止
  次曲へ


待機画面と予約一覧:
  表示画面では、待機中に画像/動画/音声のプレイリストをループできます。
  予約が入ると、設定秒数だけ予約一覧を表示してから曲を再生します。


Windows通常起動:
  KaraokeLocalはタスクトレイに常駐します。
  トレイアイコンを右クリックすると、TOP画面・表示画面・管理画面を開く、または終了できます。
  二重起動は防止され、2回目以降の起動操作では新しいプロセスやブラウザ画面を追加しません。
  起動時に自動表示されるブラウザはTOP画面です。
  初期設定では、起動中だけタスクバーを自動非表示・アプリ点滅OFFにし、通常終了時に元へ戻します。
  この動作は管理画面からOFFにできます。


終了:
  タスクトレイのKaraokeLocal → 終了
  トレイが表示されない場合は stop.bat
