# ITSUKI

**Interactive Terminal Service for Unified Karaoke Integration**

ITSUKIは、PCに保存したカラオケ動画をスマホやPCのブラウザから検索・予約し、VLCで順番に再生するローカルカラオケ統合ツールです。

## できること

- 曲名・人物・タイアップ・年代・外国語曲などから選曲
- 新曲・更新曲を週（W番号）単位で確認
- 人物検索の完全一致 / 部分一致 / 前方一致、別名義・グループ候補の表示切替
- 人物ごとに歌手 / 作詞 / 作曲 / 編曲の担当曲を横断表示
- スマホやPCから予約、予約順変更、リモコン操作
- 選曲者に加えて「一緒に歌う人」を参加者から登録
- 「＋♪ とりあえず300」に気になる曲を一旦保存
- DBが無い動画も「フォルダから選曲」から直接予約
- VLCによる動画再生、曲終了時のNEXT表示・目安Kcal演出
- 履歴・ランキング（総合 / 年別 / ジャンル別）と過去Excelデータの取込・出力
- 歌手別TOP3・再生ゼロ曲タグ、再生ゼロ曲からのおすすめ
- ON/OFFボーカル判定
- 動画↔楽曲DBの紐づけ監査 / 監査Excelでの一括修正・確認状態・通報ステータス管理
- 動画ルート直下の `.itsuki` にルート設定・DB別紐づけを保存し、SSD/HDDの持ち寄り・クローン・別PC運用で自動引継ぎ
- 設定・履歴・紐づけ情報などの選択バックアップ / 復元
- Googleスプレッドシートへの予約リスト同期（任意）
- YouTube / ニコニコ動画 / Bilibili のURLから動画サイト予約（任意・標準OFF）

## 更新履歴

### 正式公開の主な変更（v1.4.0 → v1.4.33）
- **履歴とランキング：** 履歴を日付別に表示し、日付・歌唱者で絞り込み。歌唱者の公開は管理画面で制御できます。総合／年別ランキングの個人別表示、共演者を含む集計、曲詳細の「過去に歌った人」、人物別の人気順・映像タグ絞り込みを追加しました。
- **履歴データの移行：** ExcelテンプレートにDB曲一覧と曲ID照合を追加。曲IDのみの過去履歴も、現在の紐づけ動画から再予約できます。複数映像は選択可能。再生履歴の動画パスを保持し、後日確認済みになった紐づけを同一曲IDの集計に反映します。
- **紐づけの安全性：** 自動判定は管理者向けの候補として保持し、確認済み動画のみ一般向け曲ID検索・予約バリエーションに反映。未確認／要確認／未紐づけはファイル名・パスと警告表示で識別できます。
- **動画ルート共有JSON：** 本体での紐づけ変更をルート共有JSONへ書き戻し。別PCで異なる紐づけがある場合は両方を保護し、採用する側を手動選択。処理中のボタンは「更新中…」を表示します。
- **Googleスプレッドシート：** 既存シートの見出し行と出力列（例：曲名C列、共演者D～M列）を指定できるようにしました。指定セルだけ更新し、既存の見出し・書式・未指定セルを維持。セットアップ手順をHTML化しました。**この機能を使う場合は最新版Code.gsへ差し替えて再デプロイしてください。**
- **使いやすさと安定性：** リモコンの接続先QR再スキャン、管理画面の保存中表示、自然終了時のカロリー計算修正、検索・予約画面の読み込み安定化、再生ゼロ曲の履歴更新即時反映、紐づけ状態別の見出しなどを改善しました。
