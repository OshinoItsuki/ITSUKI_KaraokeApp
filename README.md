# ITSUKI

**Interactive Terminal Service for Unified Karaoke Integration**

ITSUKIは、Windows PCに保存したカラオケ動画を、同じネットワークのスマホやPCから検索・予約してVLCで再生するローカルカラオケシステムです。動画をスキャンすれば、楽曲DBが未設定でも「フォルダから選曲」できます。

**最新の正式公開版：v1.5.28（2026年10月29日）**

## 主な機能

- **検索・選曲：** 曲名・人物（歌手・作詞・作曲・編曲）・タイアップ・新曲・年代・動画制作者・フォルダから選曲。DBに登録されていない動画もファイル名検索から探せます。
- **メドレー：** DBに登録されたメドレーを一覧表示し、予約画面で収録曲と曲順を確認できます。
- **再生・予約：** VLCによる動画再生、キー・テンポ・音量調整、スマホからの予約とリモコン操作、選曲者・共演者・歌唱順・周回表示。
- **履歴・ランキング：** 歌唱履歴、総合・年別・ジャンル別ランキング、再生ゼロ曲、過去曲からの再予約。
- **複数ライブラリ：** SSD/HDDごとの楽曲DB・動画ルート、スキャン、ON/OFFボーカル判定、同一動画グループの履歴・紐づけ共有。
- **管理・監査：** 動画と楽曲DBの紐づけ確認・通報、監査Excel出力・取り込み、設定と履歴のバックアップ。
- **任意の連携：** Googleスプレッドシートへの予約リスト同期、動画サイトURLからの予約（標準OFF）。

## 初めて使う場合

1. Windows PCにVLC media playerを用意し、公開ZIPを展開して `ITSUKI.exe` を起動します。
2. 管理画面から動画ルートと必要に応じて楽曲DB（`.kvdb` / `.sqlite3` / `.ylexa`）を設定し、スキャンします。
3. TOP画面に表示された接続先を同じLAN・Wi-Fiの端末で開き、曲を選んで予約します。

詳しい操作や管理者認証、ネットワーク設定は、同梱の [管理者ヘルプ](help.html) を参照してください。

## バージョン更新時の注意

- 更新前に、管理画面で**設定・履歴・紐づけ**をバックアップしてください。動画ルート内の `.itsuki` も保管を推奨します。
- 確認済みの曲IDや動画の紐づけは、ドライブが見つからないだけでは上書きしない方針です。同一ライブラリグループでも、動画の照合・競合の確認は管理者が行ってください。
- EXEの更新後は必要に応じて動画を再スキャンしてください。従来の設定ファイルや履歴を削除する必要はありません。
- 予約リストのGoogle同期などを利用する場合は、導入済みの `Code.gs` とデプロイ設定を確認してください。

- **動作の軽量化：** 曲情報の読み込み、再生回数・履歴の集計、同一ライブラリグループの照合を高速化。スキャン終盤の進捗表示も改善。
