ITSUKI 管理者ヘルプ

ITSUKIは、PCに保存したカラオケ動画をスマホやPCのブラウザから探し、予約し、VLCで順番に再生するローカルカラオケ統合ツールです。楽曲DBが未完成でも、スキャン済み動画をフォルダ階層から直接選曲できます。

正式名称
Interactive Terminal Service for Unified Karaoke Integration

1. 導入

  1. GitHub Releasesから最新の公開ZIPを取得します。
  2. ZIPを任意のフォルダへ展開します。中身は ITSUKI.exe と README.txt です。
  3. VLC media playerをインストールしておきます。
  4. ITSUKI.exe を起動します。必要ならEXEのショートカットをデスクトップへ作成します。
  5. 初回はブラウザでTOP画面が開き、表示用Chromeも起動します。

設定・履歴・ランキング・紐づけ情報はEXEとは別にPCごとのデータ領域へ保存されるため、通常の更新ではEXEを入れ替えてもデータを引き継げます。

2. 初回設定

  1. リモコン画面から管理者PINを入力します。初期PINは 0000 です。
  2. 管理画面で管理者PINを変更します。
  3. 楽曲DB、動画ルート、VLC、待機画面など必要な項目を設定します。
  4. 「基本設定を保存」を押します。
  5. 「動画を再スキャン」を実行します。進捗は％とプログレスバーで確認できます。

スキャンはバックグラウンドで続くため、開始後にTOPや検索画面へ移動しても問題ありません。

3. 楽曲DB設定

対応形式

.kvdb / .sqlite3 / .ylexa に対応しています。KVDBの人物リレーションが存在する場合、別名義・所属グループ・所属メンバーも人物検索へ反映します。

単一DBモード

1つの楽曲DBを複数の動画ルートで共通利用します。一般的な構成ではこちらを使います。

複数DBモード

楽曲DBと動画ルートを1対1で組にします。動画は所属ルートに対応したDBだけで紐づけます。

📁ボタン

ITSUKI本体PCから管理画面を開いた場合だけ、Windowsのファイル/フォルダ選択を利用できます。スマホ・別PCでは安全のためダイアログを起動せず、パスを手入力します。

4. 動画ルート・除外・スキャン

動画ルートには、選曲対象にする動画が入っている最上位フォルダを指定します。ITSUKIは設定ルート外を選曲画面へ公開しません。

除外

作業中・未完成・一時保管など、選曲へ出したくないフォルダやファイルを除外設定へ登録します。除外配下はスキャン対象にもフォルダ選曲にも出ません。

再スキャンが必要な時

  • 動画ルートを追加・変更した
  • 動画を追加・削除・移動した
  • 除外設定を変更した
  • フォルダ選曲の表示拡張子を変更した

フォルダ選曲用の階層情報はスキャン時に保存されます。選曲中に毎回ディスクを探索しないため、表示は高速です。スキャン後に追加した動画は、次の再スキャンまでフォルダ選曲には表示されません。

5. 選曲・検索

TOPから曲名、歌手名、新曲・更新曲、MV/PV、LIVE、アニメ・ゲーム映像、年代、キーワード、タイアップ、外国語曲、ランキング、履歴などの入口を選べます。

楽曲DBに紐づいた動画は曲情報を使って検索できます。人物リレーション経由でヒットした場合は「別名義」「所属グループ」「所属メンバー」など理由を表示します。

外国語曲

英語・北京語・広東語・ドイツ語・スウェーデン語など、KVDBの言語タグを使って分類します。国旗は画像で表示します。

6. フォルダから選曲

DB情報を使わず、スキャン時に保存した動画フォルダ階層から動画へたどり着く選曲方法です。DB未紐づけ動画も予約できます。画面はデジ像のファイル選択UIを参考にした黒・濃灰・シアン基調で、選択位置と件数、現在パスが一目で分かる構成です。

  • 表示対象は動画ルート配下だけ
  • 除外設定を反映
  • 許可した動画拡張子だけ表示
  • ファイル移動・削除などの編集機能はなし
  • 名前順の昇順/降順に対応
  • 「編集」からファイル名・フォルダ名を絞り込み可能
  • タップ選択、ダブルクリック、十字キー＋決定に対応

7. 予約と再生

動画を選ぶと既存の予約確認画面へ進みます。選曲者を指定して予約すると、予約リストへ追加されます。再生前には設定に応じて予約一覧を表示し、その後VLCで動画を再生します。

予約リストでは順番変更や削除ができます。管理者画面から全削除もできますが、危険操作として確認が入ります。

8. リモコン

通常リモコンでは再生/一時停止、送り戻し、音量変更、待機BGM音量などを操作できます。「はじめから」「演奏停止」「次曲へ」は誤操作防止の確認を表示できます。確認のON/OFFは管理画面で設定します。

管理者リモコンは管理者認証後だけ利用でき、現場で使う管理操作を通常設定画面から分離しています。

9. 表示画面・VLC

表示画面は専用Chrome、動画はVLCを使用します。イベント中のタスクバー自動非表示・点滅抑制も設定できます。ITSUKIを正常終了すると、VLCと表示Chromeを閉じ、タスクバー設定を起動前へ戻します。

Windowsのファイル/フォルダ選択を開く時は、VLCと表示画面を一時的に隠して選択ダイアログを最前面へ出します。選択終了後に再生状態へ復帰します。

10. 音量・音ズレ

ルート別標準音量

会場で実際に動画を再生し、リモコンでちょうどよい音量に合わせてから「今の音量を標準音量に保存する」を押します。数値を手入力するのではなく、実際の再生音量を基準として保存します。

A/V補正

標準A/V補正を管理画面で設定できます。再生中は管理画面から50ms単位で一時調整でき、次の曲では標準値へ戻ります。

11. ON/OFFボーカル判定

動画ファイル名に含まれる語からONボーカル/OFFボーカルを判定できます。全ルート共通またはルート別にルールを設定できます。

on / off のような短い英字は、_on_、(off)、[on] のようなタグ状の区切りを優先し、曲名中の「Fight on!」「Smoke On The Water」「edition」などを誤判定しにくい仕様です。

12. 参加者・管理者

参加者は1行1名で登録し、予約確認画面の選曲者候補に使います。管理者PINは4～12桁の数字です。管理画面URLはPCごとに生成され、管理者認証後に利用します。

管理画面上部には直近45秒以内に参加者側ページから通信した端末数を表示します。

13. Googleスプレッドシート同期

必要な場合だけGoogle Apps Script経由で予約リストを同期できます。同期ONは起動中だけ有効で、次回起動時はOFFに戻ります。送る列と列順は管理画面から選択できます。

ネットワーク障害が起きてもローカルの予約・再生を止めないバックグラウンド同期です。

14. バックアップ / 復元

設定、参加者、会場設定、Google設定、管理者PIN、動画スキャン/紐づけDB、予約、履歴・ランキングなどを項目別にエクスポート/インポートできます。

「履歴だけ移行したいが、現在の曲紐づけDBは上書きしたくない」といった選択復元ができます。バックアップには認証情報が含まれる場合があるため、公開しないでください。

15. ITSUKIの更新

公開版は起動中にGitHub Releasesの最新版を定期確認します。現在より新しい版がある場合、操作ブラウザ上部に赤い帯で通知します。通知帯にはリンクやポップアップはありません。

更新版のZIPは管理画面の「更新」からダウンロードしてください。通知が不要なら管理画面でOFFにできます。

  1. 管理画面で最新版ZIPをダウンロードします。
  2. ITSUKIを終了します。
  3. ZIPを展開し、新しい ITSUKI.exe を配置します。
  4. 新しいEXEを起動します。PCごとの設定データはそのまま利用されます。

16. トラブル時

新しい動画が見えない

動画ルート・除外・拡張子を確認し、動画を再スキャンしてください。

フォルダ選曲に追加ファイルが出ない

仕様です。階層情報は再スキャン時に固定保存されるため、動画追加後に再スキャンしてください。

管理画面の📁が押せない

Windowsのファイル選択はITSUKI本体PCで管理画面を開いた時だけ利用できます。

更新通知が出ない

管理画面の更新欄で、更新確認先・通知設定・直近の確認結果を確認してください。

終了後も表示が残った

通常は安全終了処理と外部フェイルセーフでVLC・表示Chrome・タスクバー設定を復元します。デバッグログにエラーがある場合は、そのログを保存して確認してください。
