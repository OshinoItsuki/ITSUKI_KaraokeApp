# KaraokeLocal

ローカルネットワーク上で使う、カラオケ選曲・予約・再生管理ツールです。

PCをサーバー兼プレイヤーとして使い、スマホや別PCのブラウザから曲検索・予約・予約リスト操作を行えます。  
楽曲情報は既存のゆかりスター互換SQLite / YLEXA DBを読み取り専用で利用し、動画との紐づけや予約履歴はKaraokeLocal側で別管理します。

## 主な機能

- スマホ / PCブラウザから曲検索・予約
- 曲名、歌手、作詞、作曲、編曲、タイアップ、シリーズ等から検索
- ファイル名・フォルダ名・フルパスだけで検索するモード
- 動画ルート配下をExplorer風に辿って選曲する「フォルダから選曲」
- DB未紐づけ動画もそのまま予約可能
- VLCによる動画再生
- 一時停止 / 再生 / はじめから / 演奏停止 / 次曲
- ±5秒 / ±10秒シーク
- 音量を±1% / ±5% / ±10%で調整
- ルートフォルダごとの標準音量
- A/V同期補正
- 予約順変更、削除、再生済み管理
- 予約リストCSV出力
- Googleスプレッドシートへの予約リスト同期（Apps Script経由）
- LAN / Tailscale用QRコード切り替え
- 参加者登録と選曲者選択
- PIN認証式の管理画面
- 管理者用の動画↔楽曲DB紐づけ編集
- 単一DB / ルート別複数DBモード
- 手動紐づけ設定のJSONエクスポート / インポート

## 動作環境

- Windows 11推奨
- 公開版EXE: Python不要
- ソース版: Python 3.10以降
- VLC media player 推奨
- 同一LAN、またはTailscale経由で接続可能な端末

KaraokeLocal本体はPython標準ライブラリ中心で動作します。  
QRコード生成ライブラリはリポジトリ内へ同梱しています。

## 起動方法

### 公開版を利用する場合

公開用ZIPに含まれる `KaraokeLocal.exe` を起動します。Pythonのインストールは不要です。
`KaraokeLocal.exe` のショートカットをデスクトップやスタートメニューへ作成して利用できます。

設定・履歴・ランキング・動画紐づけDBなどのPC固有データはEXE本体とは分離して `%LOCALAPPDATA%\KaraokeLocal` に保存されるため、KaraokeLocal.exeを新版へ差し替えても引き継がれます。

### 開発版 / ソース版を利用する場合

#### 1. リポジトリを取得

```bash
git clone https://github.com/<YOUR_ACCOUNT>/KaraokeLocal.git
cd KaraokeLocal
```

またはGitHubからZIPを取得して展開します。

#### 2. 起動

Windowsでは以下を実行します。

```text
start.bat
```

通常起動ではコンソールウィンドウを表示せず、バックグラウンドでKaraokeLocalを起動します。

Windowsでは起動中にタスクトレイへ常駐します。トレイアイコンの右クリックから選曲画面・表示画面・管理画面を開く、またはKaraokeLocalを終了できます。二重起動は防止され、起動時には選曲画面だけを自動表示します。

管理者認証後は、管理画面の「9. 危険操作」からKaraokeLocal本体を安全終了できます。本体PCだけでなくスマホ・別PCからも実行可能です。終了時はVLCと表示専用Chromeを閉じ、イベント用タスクバー設定を起動前へ戻してからサーバーを停止します。

エラー確認や開発時にコンソール出力を表示したい場合は、以下を使用します。

```text
start_debug.bat
```

またはコマンドラインから直接起動できます。

```bash
python app.py
```

### 公開用EXE / ZIPを生成する

開発PCで `build_public.bat` をダブルクリックします。初回だけ `.build_venv` へPyInstallerをインストールし、以後はその専用環境を再利用します。

生成物は次の場所へ作成されます。

```text
release/
├─ KaraokeLocal_vX.X.XX/
│  ├─ KaraokeLocal.exe
│  ├─ README.txt
│  ├─ README.md
│  └─ THIRD_PARTY_NOTICES.md
└─ KaraokeLocal_vX.X.XX.zip
```

公開用EXEにはWeb画面、Windowsファイル選択スクリプト、Google Sheets補助ファイルを同梱します。`app.py` や開発用バッチ、Git情報は公開用ZIPへ含めません。

標準ポートは `13585` です。

起動後、ターミナルに表示されたURLへアクセスします。

```text
選曲画面:       http://<LAN-IP>:13585/
予約リスト操作: http://<LAN-IP>:13585/queue
```

## 初回設定

初回起動時は、リモコン画面にあるテンキーから管理画面へ入ります。

管理画面を開く操作:

```text
5963
↓
メモリーセット
↓
管理者パスワードを入力
↓
メモリーセット
```

初期管理者パスワード:

```text
0000
```

通常のテンキー入力では数字が表示されます。  
`5963` → `メモリーセット` の操作後は「管理者パスワードを入力してください」と表示され、以降の入力は文字数に応じて `●` で表示されます。

管理画面へ入ったら、最初に管理者パスワードを変更することを推奨します。

管理画面のURLは固定の `/admin` ではありません。初回起動時にPCごとの推測困難な英数字パスを自動生成し、リモコンで管理者認証に成功した場合、またはタスクトレイの「管理画面を開く」からのみそのURLへ遷移します。旧 `/admin` は404になります。URLの秘匿はPIN認証に加える補助的な防御で、管理者PIN自体も引き続き必要です。

新規環境では、参加者の初期値として `Aさん`、`Bさん`、`Cさん` が登録されています。必要に応じて編集してください。

管理画面では主に以下を設定します。

1. 参加者
2. 管理者PIN
3. 楽曲DB
4. 動画ルート
5. 除外フォルダ
6. VLC
7. 再生開始ディレイ
8. A/V補正
9. ルート別標準音量（再生中の実音量から保存）
10. ON / OFFボーカル ファイル名判定ルール
11. 補助歌手フォルダ

設定後に `動画を再スキャン` を実行します。

## 楽曲DB

以下の形式に対応しています。

- SQLite
- `.sqlite3`
- `.sqlite`
- `.db`
- YLEXA

KVDBはSQLite互換DBとして直接読み込みます。`kvdb_person_relation` があれば人物の別名義・所属グループを人物検索へ展開します。

YLEXAはZIPコンテナとして認識し、内部の `ExportMusicInfo.sqlite3`（またはSQLite互換DB）をキャッシュへ展開して読み込みます。

楽曲DB自体は読み取り専用です。  
動画との紐づけはKaraokeLocal側のローカルDBへ保存されます。

### 単一DBモード

従来どおり、1つの楽曲DBを複数の動画ルートで共通利用します。

```text
楽曲DB
 ├─ 動画ルートA
 ├─ 動画ルートB
 └─ 動画ルートC
```

### 複数DBモード

動画ルートごとに利用する楽曲DBを1対1で指定できます。

```text
DB 1 ↔ 動画ルート 1
DB 2 ↔ 動画ルート 2
DB 3 ↔ 動画ルート 3
```

管理画面では最初に2組の入力欄を表示し、`DB・ルート設定を追加` から最大99組まで追加できます。

複数DBモードでは、自動紐づけ・管理者による手動紐づけ候補ともに、その動画が所属するルートに対応したDBだけを参照します。  
異なるDBで同じ `song_id` が使用されている場合でも、KaraokeLocal内部ではDB識別子を付与して衝突を防ぎます。


## 選曲

選曲画面:

```text
/
```

参加者を選択してから検索・予約します。  
選曲者が未選択の場合、予約は送信されません。

通常検索では楽曲DB情報と動画ファイル名を利用します。

### ファイル名・フォルダ名だけで検索

`ファイル名・フォルダ名だけで検索` をONにすると、楽曲DBの情報を検索条件に使用しません。

検索対象:

- 動画ファイル名
- 相対パス
- フルパス

DB紐づけが未完了の動画でも、そのまま予約できます。

### フォルダから選曲（Explorer風）

TOPの `フォルダから選曲` から、楽曲DBの紐づけ状態に関係なくKaraokeLocalへ読み込まれている動画をフォルダ階層で探せます。

```text
/folder-browser
```

- 管理画面で設定した動画ルートより下だけを参照します。PC全体や動画ルート外へは移動できません。
- KaraokeLocalの動画スキャンDBへ登録済みのファイルだけを表示します。DB未紐づけ動画も予約できます。
- 管理画面の除外フォルダ・除外ファイル設定をそのまま反映します。
- 表示対象拡張子は管理画面から設定でき、初期値は `avi, mp4` です。KaraokeLocalが動画として対応していない拡張子は指定しても公開しません。
- Explorerの「詳細」表示風に、フォルダ名・ファイル名（拡張子込み）だけを表示します。日付、時刻、ファイルサイズ、動画長は表示しません。
- 名前の昇順/降順で並べ替えできます。
- 動画再スキャン時にフォルダ選曲用の階層データを保存し、通常のフォルダ移動では動画ルートの再探索やSQLite全件検索を行いません。
- 動画ルート、除外設定、表示拡張子、動画ファイルの追加・削除・移動を反映するには、管理画面から動画を再スキャンします。
- タッチ操作に加え、画面下部の十字キー・決定・戻るボタンでもフォルダ移動と選曲ができます。
- 動画を選ぶと従来の予約確認画面を開きます。ファイルの移動、削除、名前変更などの操作はできません。

Explorer版のフォルダ取得APIと操作ロジックは共通化してあり、後から追加するデジ像風画面でも同じ仕組みを利用できます。

## 再生プレイヤー

再生プレイヤーは **VLC固定** です。

管理画面からVLC.exeのパスと出力画面を指定できます。カラオケ動画と待機用の画像・動画・音声は、指定画面でVLCを全画面・最前面で再生します。

複数ディスプレイ環境では「出力画面」から対象ディスプレイを選択できます。予約一覧は同じディスプレイの専用表示画面に表示されます。

音ズレ補正もVLCのRC制御を使用します。

## 予約リスト・再生操作

予約リスト操作画面:

```text
/queue
```

主な操作:

- 一時停止：現在曲をその位置で一時停止
- 再生：一時停止を解除して続きから再生
- はじめから：現在曲を先頭から再生
- 演奏停止：現在曲を終了し、再生済みに変更
- 次曲へ：現在曲を再生済みにして次曲を開始。停止中は未再生先頭を開始
- ±5秒 / ±10秒
- 音量 ±1% / ±5% / ±10%
- A/V補正 ±50ms
- 予約順変更
- 未再生へ戻す
- 予約削除
- CSV出力

予約を追加しただけでは自動再生されません。  
停止中に `次曲へ` を押すと、予約リストの未再生先頭から再生を開始します。

### 会場ごとの標準音量を実音量から保存

ルート別の標準再生音量は数値を手入力しません。会場で実際にカラオケ動画を再生し、リモコンでちょうどいい音量へ調整したあと、管理画面の `今の音量を標準音量に保存する` を押します。KaraokeLocalが再生中動画の所属ルートと現在のVLC音量を自動取得し、そのルートの標準値として保存します。次の曲から、その動画ルートでは保存した音量が初期値になります。

### ファイル名からON / OFFボーカルを判定

管理画面でONボーカル用・OFFボーカル用の判定語を登録できます。全動画ルートで同じルールを使うか、動画ルートごとに別ルールを持つか選択できます。初期値はON側が `on` / `うたいり`、OFF側が `off` / `Ai off` / `Vo off` です。

`on` / `off` のような短い英数字は通常の部分一致を行わず、`_on_`、`(off)`、`[on]` などファイル名上でタグとして区切られている場合だけ判定します。そのため `Fight on!`、`Smoke On The Water`、`edition` など曲名由来の文字列は判定対象になりません。長めの固有ルール（例: `Ai off`、`off vocal`、`うたいり`）はフレーズとして判定できます。

複数動画がある曲では、判定できた動画を選択欄で `[ONボーカル]` / `[OFFボーカル]` と表示し、予約確認画面にも種別を表示します。

## 待機画面・予約一覧

待機中は、管理画面に登録した画像・動画・音声のプレイリストをVLCでループ再生します。予約が入ると待機用VLCを停止し、専用表示画面に予約一覧を表示してからカラオケ動画へ切り替えます。

専用表示画面は起動時に自動表示でき、選択したディスプレイで全画面表示します。

## LAN / Tailscale

予約リスト画面には選曲画面用QRコードがあります。

`LAN` と `Tailscale` を切り替え可能です。

LAN例:

```text
http://192.168.1.50:13585/
```

Tailscale例:

```text
http://100.x.x.x:13585/
```

Tailscaleが利用可能なPCでは `tailscale ip -4` からIPv4アドレスを自動取得します。

## 管理者用 紐づけ編集

管理画面下部の `管理者用 選曲・紐づけ編集` から、動画を検索して楽曲DBとの紐づけを編集できます。

検索結果には以下を表示します。

- ファイル名
- フルパス
- 相対パス
- 現在の紐づけ
- 紐づけ状態

そこからDB候補を検索し、別の曲への再紐づけや紐づけ解除ができます。

通常の選曲画面からは紐づけ編集できません。

## 手動紐づけの共有

管理画面から手動紐づけ情報をJSONでエクスポート / インポートできます。

主に以下を使って別PCでも照合します。

- 相対パス
- ファイル名
- song_id
- 曲名
- 歌手名

動画ルートのドライブ文字がPCごとに違っていても移植しやすい形式です。

## PCごとの保存データ

Windowsでは以下に保存します。

```text
%LOCALAPPDATA%\KaraokeLocal\
```

主な内容:

```text
config.json
karaoke_local.sqlite3
cache\
exports\
```

アプリ本体のフォルダとは分離されているため、新しいバージョンを別フォルダへ展開しても同じWindowsユーザーなら設定を引き継げます。

これらのPC固有データはGit管理対象にしないでください。

## 注意事項

- 楽曲DBは必ずバックアップを取ったうえで運用してください。

- 動画ファイルの移動・削除後は再スキャンしてください。
- 初期管理者パスワード `0000` は運用前に変更してください。
- LANへ公開するため、信頼できるネットワーク内での利用を推奨します。

#### 曲名非表示予約について

非表示は予約単位で保存されます。通常予約と非表示予約を同じキューへ混在できます。再生に使うローカルDB・動画パス自体は変更せず、利用者へ公開する予約情報だけを伏せるため、再生や履歴・ランキング集計には影響しません。
