ITSUKI 管理者ヘルプ

Interactive Terminal Service for Unified Karaoke Integration

ITSUKIは、PCに保存しているカラオケ動画を、スマホやPCのブラウザから検索・予約し、VLCで順番に再生するローカルカラオケ統合ツールです。

楽曲DBを使った検索だけでなく、DBが無い状態でもスキャン済みフォルダから動画ファイルを直接探して予約できます。 まず動画だけで使い始め、あとからDBを整備して検索機能を増やすこともできます。

準備

表示画面・VLC

ITSUKIは、動画再生に VLC media player、予約一覧などの表示画面に Google Chrome を使用します。どちらかがPCに入っていない場合は、先に公式サイトからインストールしてください。

VLC公式サイトからダウンロード Google Chrome公式サイトからダウンロード
すでにインストール済みなら、そのまま次へ進んでOKです。
VLCの場所は通常自動検出されます。見つからない場合は管理画面から vlc.exe を指定できます。

導入

このヘルプは、公開ZIPの展開が終わっている状態から説明します。

  1. ITSUKI.exe をダブルクリックして起動します。
  2. 初回はTOP画面と表示用Chromeが起動します。
  3. 必要なら ITSUKI.exe のショートカットをデスクトップなどへ作成します。
  4. 管理画面を開いて初期設定を行います。管理画面の開き方は リモコン の項目を確認してください。

設定・履歴・ランキング・予約・紐づけ情報などはEXEとは別のPCデータ領域へ保存されます。通常のアップデートではEXEを入れ替えても引き継がれます。

初回設定

  1. リモコン から管理者認証して管理画面を開きます。
  2. 管理者PINを自分用に変更します。
  3. 動画ルートを設定します。楽曲DBは後からでも構いません。
  4. 必要に応じてVLC、待機画面、音量、参加者などを設定して保存します。
  5. 「動画を再スキャン」を実行します。

スキャンはバックグラウンドで続くため、スキャン開始後にTOPやリモコンへ移動しても問題ありません。管理画面へ戻れば進捗％とプログレスバーを再表示します。

動画ルートとスキャン

動画ルートには、選曲対象にしたい動画が入っている最上位フォルダを指定します。ブラウザから辿れるのは、設定した動画ルート配下だけです。

  • 管理画面の📁ボタンはITSUKI本体PCから開いた場合だけ利用できます。
  • 除外設定へ登録したフォルダ・ファイルはスキャンにもフォルダ選曲にも出ません。
  • フォルダ選曲に表示する拡張子は管理画面で変更できます。標準は avi, mp4 です。
  • 動画を追加・削除・移動したとき、動画ルートや除外設定を変えたときは再スキャンしてください。

フォルダ階層は再スキャン時に保存します。選曲中に毎回ディスクを探索しないため、フォルダ画面は高速に表示されます。

音量・音ズレ

ルート別標準音量

会場で実際に動画を再生し、リモコンでちょうど良い音量へ調整してから、管理画面または管理者リモコンの「今の音量を標準音量に保存する」を押します。動画ルートごとに基準音量を保存できます。

A/V補正

標準A/V補正は管理画面で設定できます。再生中だけ50ms単位で一時調整でき、次の曲では標準値へ戻ります。

使い方

TOP画面

参加者が最初に使う選曲メニューです。上段の「新曲・歌手名・曲名・フォルダから選曲」が基本の入口で、中段に各種カテゴリ検索、下段にとりあえず300・履歴・予約一覧・リモコンがあります。

楽曲DBが設定されていない場合、DB情報が必要なボタンだけグレーアウトします。フォルダ選曲などDB不要の機能は利用できます。

フォルダから選曲

楽曲DBを使わず、動画ルート配下のフォルダを辿って動画ファイルを直接選ぶ画面です。スキャン時に保存した階層キャッシュを使うため、フォルダ移動は高速です。

  • 一覧をタップ、または十字キーで選択し「決定」で開きます。
  • フォルダは下の階層へ進み、動画ファイルは選曲予約画面へ進みます。
  • 「編集」から名前の絞り込みや並び順を変更できます。
  • DB未紐づけの動画でも予約できます。

検索画面

曲名・歌手名・タイアップ・キーワードなどから楽曲DBを検索します。検索種別を切り替え、候補の動画から「予約」を押すと選曲予約画面へ進みます。

楽曲DBが未設定の場合、この種類のDB検索機能はTOP画面でグレーアウトします。

とりあえず300

気になった曲をすぐ予約せず、一旦保存しておく全端末共通リストです。最大300曲まで保存でき、誰が追加したかは記録しません。

  • 同じ曲は重複登録しません。
  • 一覧から選曲予約画面へ進めます。
  • この一覧から予約送信が成功すると自動でリストから消えます。
  • 手動削除、管理画面からの一括削除もできます。

選曲予約画面

曲・動画を選んだ後に表示される確認画面です。曲情報を確認し、選曲者を選んで予約します。「＋♪ とりあえず300」は選曲者を選ばなくても利用できます。

未再生の通常予約を予約曲リストから開いた場合は、新しい予約を追加するのではなく選曲者を変更できます。シークレット予約は後から内容編集できません。

予約曲リスト

予約は「未再生」「再生中」「再生済み」の3状態で表示します。未再生だけ並び替え可能で、再生中・再生済みは位置を固定します。

  • 未再生：並び替え・削除・予約内容の編集
  • 再生中：削除・詳細から再予約
  • 再生済み：削除・詳細から再予約

リモコン

再生 / 一時停止、シーク、音量、次曲などをブラウザから操作します。「はじめから」「演奏停止」「次曲へ」は、管理画面の設定により確認画面を表示できます。

管理画面を開く

管理者用の設定画面はリモコンから開きます。

  1. リモコン画面の管理者認証を開きます。
  2. 管理者PINを入力します。初期PINは 0000 です。
  3. 認証に成功すると管理画面を開けます。
  4. 初回設定が終わったら、管理画面でPINを変更しておくことをおすすめします。

管理画面

参加者、管理者PIN、DB、動画ルート、VLC、Google同期、バックアップ、紐づけ、更新、本体終了などを設定・管理します。上部のナビゲーションから各設定へ直接移動できます。

接続中端末数やスキャン進捗も管理画面上部で確認できます。Windowsのフォルダ / ファイル選択ダイアログを使う設定だけは本体PC限定です。

チュートリアル

選曲・検索

  1. TOP画面で「曲名」または「歌手名」を開きます。
  2. 検索語を入力し、候補から曲を選びます。
  3. 動画が複数ある場合は使いたい動画を選びます。
  4. 選曲予約画面で選曲者を選び「予約」を押します。

とりあえず300

  1. 気になる曲の選曲予約画面を開きます。
  2. 「＋♪ とりあえず300」を押します。選曲者の選択は不要です。
  3. 後でTOPの「とりあえず300」を開きます。
  4. 予約したい曲の「選曲」を押し、通常どおり予約します。
  5. 予約送信が成功すると、その曲は300リストから自動削除されます。

フォルダから選曲

  1. TOPの「フォルダから選曲」を開きます。
  2. フォルダを順番に進み、動画ファイルを探します。
  3. 一覧をタップ、または十字キーで選択し「決定」を押します。
  4. 選曲予約画面で選曲者を選んで予約します。

DBが無くてもこの手順で予約できます。表示されない動画がある場合は、動画ルート・除外・表示拡張子を確認して再スキャンしてください。

予約と再生

  1. 予約すると「予約曲リスト」の未再生へ追加されます。
  2. 必要なら未再生の曲だけ順番を変更します。
  3. ITSUKIは先頭の未再生予約を再生中へ移し、VLCで再生します。
  4. 再生が終わると再生済みへ移ります。
  5. もう一度歌いたい場合は、再生済みの「詳細・再予約」から新しい予約として送ります。

リモコン

  1. TOPまたは予約一覧から「リモコン」を開きます。
  2. 再生 / 一時停止、シーク、音量などを必要に応じて操作します。
  3. 「はじめから」「演奏停止」「次曲へ」は確認画面を読んでから実行します。
  4. 管理操作が必要なら管理者認証から管理画面を開きます。初期PINは 0000 です。

便利機能

楽曲DB

.kvdb / .sqlite3 / .ylexa に対応しています。KVDBでは人物の別名義・所属グループ・所属メンバーなどの関連情報も検索へ反映できます。

楽曲DBは必須ではありません。
DBが無い場合でも、フォルダから選曲から動画ファイルを直接探して予約できます。

楽曲DBを自分で作りたい場合は、公開しているDB編集ツールを利用できます。

KaraokeSong DB Editorはこちらからダウンロードできます

ON/OFFボーカル判定

動画ファイル名に含まれる語からONボーカル / OFFボーカルを判定できます。全ルート共通、または動画ルートごとに判定語を設定できます。

on / off のような短い英字は、_on_、(off)、[on] などタグ状の区切りを優先して判定し、曲名中の通常単語を誤判定しにくい仕様です。

参加者・管理者

参加者は管理画面で1行1名として登録し、予約画面の選曲者候補に使います。管理者PINは4～12桁の数字です。

Windowsのファイル / フォルダ選択ダイアログだけは本体PC限定ですが、ITSUKIの終了など管理操作は認証済みのスマホや別PCからも行えます。

Googleスプレッドシート同期

予約追加・削除・並び替え・再生状態の変更に合わせて、現在の予約リストをGoogleスプレッドシートへバックグラウンド同期できます。ネットワーク障害が起きてもローカルの予約・再生は止めません。

管理画面から設定用の手順ファイルを確認しながら設定できます。
Google同期欄には「Code.gs を開く」と「セットアップ手順を開く」が用意されています。別途ファイルを探さなくても、管理画面を見ながら順番に設定できます。
  1. 管理画面のGoogle同期欄で「セットアップ手順を開く」を開きます。
  2. 「Code.gs を開く」からApps Scriptへ貼り付けるコードを確認します。
  3. 管理画面に表示される同期トークンをApps Script側へ設定します。
  4. Apps ScriptをWebアプリとして公開し、発行されたURLを管理画面へ貼り付けます。
  5. 送信する列と列順を選び、「Google同期設定を登録」を押します。
  6. 必要なイベントのときだけ同期ONにします。同期ONはITSUKI終了時に自動でOFFへ戻ります。

バックアップ / 復元

設定、参加者、音量、Google設定、管理者PIN、動画スキャン / 曲紐づけ、予約、とりあえず300、履歴・ランキングなどを項目別にエクスポート / インポートできます。

「履歴だけ移したいが、現在の紐づけDBは上書きしたくない」といった選択復元ができます。認証情報を含む可能性があるため、バックアップJSONは公開しないでください。

更新

新しい公開版がある場合、参加者向け操作画面の上端へ赤い帯で通知できます。通知はポップアップではなく、管理画面でOFFにもできます。

  1. 管理画面の更新欄で最新版ZIPをダウンロードします。
  2. ITSUKIを終了します。
  3. ZIPを展開し、新しい ITSUKI.exe、README.txt、help.html を配置します。
  4. 新しいEXEを起動します。設定・履歴などはそのまま引き継がれます。

Q&A

Q. 新しい動画を追加したのに表示されません

A. 動画ルートへファイルを追加しただけではフォルダ選曲の階層キャッシュは更新されません。管理画面で「動画を再スキャン」を実行してください。

Q. 楽曲DBがありません

A. DBなしでも利用できます。TOPの「フォルダから選曲」からスキャン済み動画を直接探してください。詳しくは フォルダから選曲 を確認してください。

Q. 管理画面の📁ボタンが使えません

A. Windowsのファイル / フォルダ選択は、ITSUKIを起動している本体PCから管理画面を開いた場合だけ利用できます。スマホや別PCではパスを手入力してください。

Q. DB検索ボタンがグレーアウトしています

A. 楽曲DBが未設定、または読み込みできていません。DBを使わず選曲する場合はフォルダ選曲を利用できます。DBを利用する場合は管理画面でDBパスを設定して再スキャンしてください。

Q. 更新通知が出ません

A. 管理画面の更新欄で、更新通知がONになっていることと直近の確認結果を確認してください。

Q. 終了後もVLCや表示Chromeが残ります

A. 通常終了ではVLC・表示Chrome・タスクバー設定をまとめて復元します。問題が続く場合はデバッグモードのログを保存してください。
